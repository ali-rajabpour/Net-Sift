## Developer Certificate of Origin

Every commit must be signed off. Add a sign-off line to each commit message:

```

```

Create it automatically with `git commit -s`. The sign-off certifies the
Developer Certificate of Origin 1.1 (https://developercertificate.org/): in short,
that you wrote the patch or have the right to pass it on under the project's
license.
